Help

Frequently asked questions

Direct answers about price, supported platforms, privacy and open source. If your question isn't here, ask on the community Discord.

Is TikLive TTS free?

Yes, TikLive TTS is 100% free and open source. There is no paid tier, no locked features, and no subscription. Development is supported by voluntary donations that never gate access to anything.

Does it work with TikTok Live, Twitch and YouTube at the same time?

Yes. TikLive TTS connects to all three platforms at once and merges every message into a single ordered voice queue, with a badge showing which platform each message came from. You don't have to pick a single platform to stream on.

Do I need to create an account or sign in?

No. TikLive TTS is a desktop app that runs locally on your computer. No sign-up, account or login is required to read your chat out loud.

Does it work with OBS?

Yes. TikLive TTS includes ready-made overlays you can add as a Browser Source in OBS: gift alerts, like counter and follower counter, all served locally without relying on external services.

Is it open source?

Yes, the full source code is published on GitHub under an open license. Anyone can review it, modify it or contribute.

How many languages can it read chat in?

TikLive TTS includes voices in 13 languages, including Latin American Spanish and other variants, to match each streamer's audience.

What data does the app collect?

TikLive TTS runs locally: it requires no account, doesn't send chat content to any of its own servers, and this website uses no tracking cookies. Full details are in the privacy policy.

Can it filter spam or blocked words in chat?

Yes. TikLive TTS includes an anti-spam filter that blocks repeated messages, overly long text and blocked words, plus moderation tools like muting or banning viewers.

What operating system does it run on?

TikLive TTS ships as an NSIS installer for Windows. Updates are published through GitHub Releases.

What happens if the connection to TikTok, Twitch or YouTube drops mid-stream?

TikLive TTS has backoff-based auto-reconnection: if a platform drops the stream or changes state, the app automatically tries to recover the connection without the streamer having to restart anything manually.
