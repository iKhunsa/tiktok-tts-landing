Privacy Policy

Last updated: August 2026

TikLive TTS runs on your computer and requires no accounts. Since version 1.7.1 the app sends usage and analytics data to a project-run server — section 2 explains exactly what, why, and for how long it's kept.

1. The app runs locally

The chat messages it reads come directly from the platforms you connect (TikTok Live, Twitch, YouTube, Kick) and are processed locally to generate the voice and the overlays. The content of those messages never leaves your computer and is not part of the telemetry described below.

2. Telemetry and analytics

The app sends usage data to the project's telemetry server (telemetria.tiklivetts.es), to understand how the app is used, prioritize features, and fix bugs faster. This is what's collected:

  • Machine identifier: a one-way hash of your Windows username and computer name — not your real name, only used so one install isn't counted twice.
  • Session data: when you open and close the app, session length, app version and OS version.
  • Approximate location: country and city derived from your IP. Your exact IP and real address are never shown or shared.
  • Platform connections: which platforms you connect (TikTok/Twitch/YouTube/Kick) and how many channels, without any chat content.
  • Identity of the channel you connect: your username, public display name, avatar and follower count — fetched from that platform's own public API (the same info anyone would see visiting your channel), at most twice per channel.
  • Feature usage: counts of how many times TTS, music, the soundpad, or moderation filters were used — never message content or who wrote them.
  • Settings: which toggles you have enabled (booleans) — never your playlists, banned-user lists, or free text.
  • Technical errors: error message and stack trace if something breaks, so it can be fixed — trimmed, with no chat content.

This data is never sold or shared with third parties, and is never used for advertising unrelated projects. It's kept for up to 365 days and then deleted automatically.

3. Your rights

You can request deletion of the data tied to your install by reaching out on GitHub or the community Discord. There's no in-app switch yet to turn telemetry off from a menu; to stop it entirely, you can clear or delete the telemetry.json file in the app's data folder.

4. This website

This site is a static page: it uses no tracking cookies, no analytics and no forms that collect personal data. The typography is loaded from Google Fonts, so your browser makes a request to Google's servers when the page loads (see Google's privacy policy).

5. External links

The site links to third-party services (GitHub, Discord, YouTube, TikTok, Twitch, Kick). Each has its own privacy policy, which applies when you visit those sites.

6. Donations

Donations are made directly through the Bitcoin network or the Lightning Network. This site only displays public addresses: it processes no payments and stores no financial information.

7. Contact

For any privacy questions, open an issue on GitHub or ask in the community Discord.
